개인정보 처리방침

공개 전 검토본 · 시행일 미정

낚시 캘린더 운영자 피클은 출조 기록 앱과 계정 관리 웹페이지의 개인정보를 아래와 같이 처리합니다. 이 문서는 현재 기능과 공개 전에 확정할 운영 사항을 담고 있습니다. 개인정보 보호 및 권리행사 문의는 www139455@naver.com으로 받습니다.

1. 처리 목적과 법적 근거

회원 가입과 본인 계정 확인, 로그인과 비밀번호 재설정, 닉네임 중복 방지, 계정·기록 접근 권한 확인에 필요한 정보를 처리합니다. 이용자가 요청한 출조 기록의 저장·조회·수정·삭제, 기기 간 동기화와 충돌 해결, 탈퇴와 웹 삭제 요청 처리에도 필요한 정보를 사용합니다. 이러한 처리의 근거는 서비스 계약 체결·이행에 필요한 범위의 「개인정보 보호법」 제15조제1항제4호입니다. 별도 동의가 필요한 처리는 목적·항목·기간과 거부 효과를 알리고 동의를 받은 범위에서 진행합니다.

위치·사진과 같은 선택 기능은 이용자가 선택할 때 사용합니다. 기기 권한을 거부해도 해당 권한 없이 이용할 수 있는 기능은 계속 이용할 수 있습니다. 개인위치정보에 관한 법정 동의가 필요한 경우에는 권한 요청과 별도로 위치 이용 조건을 알리고 동의를 얻어야 합니다. 현재 앱은 기기의 위치 권한을 사용하며, 별도의 개인위치정보 안내·동의 절차는 공개 전 확인 항목입니다.

2. 처리하는 개인정보와 수집 방법

회원 가입·인증에는 이용자가 입력한 이메일·닉네임·비밀번호, Firebase에서 생성한 계정 식별자(UID), 인증 상태와 토큰, 계정·동기화 권한 정보가 사용됩니다. 비밀번호는 Firebase Authentication에서 처리합니다. 웹 비밀번호 재설정에는 이용자가 입력한 이메일 또는 이메일 링크의 재설정 코드와 새 비밀번호가 사용됩니다.

출조 기록에는 장소명과 선택한 위치 별칭·위도·경도, 출조 시작·종료 일시, 장르, 기상 정보와 선택한 물때·수온, 조과별 어종·크기·무게, 선택한 메모·사진이 포함될 수 있습니다. 기록 검색은 기기에 불러온 기록에서 조건에 맞는 항목을 찾습니다. 동기화 권한이 있는 회원의 과거 기록 검색에는 서버 이력 조회도 사용됩니다. 지도에서 장소를 검색할 때에는 입력한 검색어를 지도 서비스로 전송합니다.

동기화 과정에서 기록과 변경 요청의 식별자, 버전·처리 시각·상태, 재처리 방지를 위한 변경 내용 확인값, 대기·실패·충돌 처리에 필요한 자료가 생성됩니다. 사진을 선택하거나 촬영하면 기기에서 사진 파일과 파일을 관리하는 데 필요한 경로·식별자 등 정보를 처리합니다.

웹 계정 삭제 요청은 이메일·비밀번호로 본인 계정을 확인합니다. 요청 문서는 UID로 구분하고 요청 상태, 서버 접수 시각, 문서 형식 버전을 보관합니다. 비밀번호·인증 토큰은 본인 확인과 접수 통신에 사용합니다. 이메일·비밀번호·인증 토큰은 접수 문서에 포함되지 않습니다. 운영자는 네이버 메일로 문의를 받습니다. 발신 이메일, 문의 내용, 답변과 요청을 확인하는 데 필요한 자료를 문의 처리 목적으로 사용합니다.

3. 기기 보관, 서버 동기화와 사진

출조 기록은 앱의 기기 저장소에 계정별로 보관합니다. 서버 동기화가 활성화된 계정에서는 기록 본문과 변경 처리에 필요한 정보가 Cloud Firestore에 올라갑니다. 출시 초기 정책은 로그인 회원에게 기록 동기화와 서버 이력 조회를 결제 없이 제공하는 것입니다. 실제 제공 여부는 서버 동기화 설정에 따릅니다. 동기화 권한이 없는 계정의 신규 기록 원본은 기기에서 관리합니다.

동기화가 활성화된 계정의 기기 기록 본문은 보통 기기 날짜 기준 오늘과 이전 30일을 중심으로 관리합니다. 열어 둔 기록, 진행 중이거나 미래인 기록, 전송을 기다리는 변경 및 해결되지 않은 충돌은 더 오래 기기에 남을 수 있습니다. 기기 캐시 정리는 서버 원본 또는 사진의 삭제와 별개입니다. 과거 기록은 연결 상태와 권한에 따라 서버에서 다시 불러올 수 있습니다.

첨부 사진은 이용자가 선택한 파일의 사본을 해당 계정의 기기 저장소에 보관합니다. 사진 파일과 기기 파일 경로는 Cloud Firestore 동기화 대상에서 제외됩니다. 공유용 임시 이미지는 생성 후 24시간이 지나면 다음 공유 작업에서 정리를 시도합니다. 공유 이미지는 사용자가 선택한 조과 정보·사진과 표시하도록 고른 항목을 합성합니다. 사용자가 갤러리에 저장하거나 운영체제 공유 화면에서 다른 앱으로 보내면, 그 사본은 갤러리·선택한 앱·수신자가 관리합니다.

4. 위치정보와 기기 권한

현재 위치 권한은 지도에서 내 위치 표시, 주변 정보 조회, 기록 작성에서 위치 찾기에 사용합니다. 이미 권한을 허용했다면 지도 화면에 들어올 때 내 위치를 조회할 수 있습니다. 앱은 백그라운드 위치 권한을 요청하지 않습니다. 기기 설정에서 위치 권한을 철회할 수 있습니다. 위치 권한을 끈 상태에서도 장소 검색이나 지도에서 지점을 선택할 수 있고, 기록 작성 화면에 장소명을 직접 입력할 수 있습니다.

조회한 좌표나 지도에서 선택한 좌표는 표시·주소 확인·날씨·해양 정보와 수역 조회에 쓰입니다. 기록을 저장할 때 장소의 좌표를 함께 선택하면 UID로 관리하는 출조 기록에 연결되며 동기화 대상일 때 서버에도 저장됩니다. 저장한 좌표는 기록을 수정해 제거하거나 기록을 삭제해 관리할 수 있습니다. 위치 사용 권한 변경은 이후의 기기 위치 접근에 적용됩니다.

카메라·사진 선택 권한은 사용자가 기록 사진을 촬영하거나 선택할 때, 운영체제가 요구하는 저장 권한은 공유 이미지를 갤러리에 저장할 때 사용합니다. 사진을 첨부하지 않아도 기록을 저장할 수 있습니다.

5. 외부 서비스와 개인정보 처리 위탁

Google Firebase를 사용해 이메일 인증, 비밀번호 재설정, 회원 프로필과 기록 동기화, 웹페이지 제공, 계정 삭제 요청 접수를 처리합니다. Firebase Authentication에는 이메일·비밀번호 등 인증에 필요한 정보가 전달됩니다. Cloud Firestore에는 UID, 닉네임·권한, 동기화 대상 기록과 변경 처리 정보, 웹 요청과 탈퇴 처리에 필요한 정보가 저장됩니다. Firebase Hosting은 계정 관리 웹페이지를 제공합니다. 서비스 제공에 필요한 처리 위탁의 업무 내용, 적용 수탁·재수탁자와 연락 경로는 실제 계약에 맞추어 확정합니다.

카카오는 지도 표시·장소 검색·주소 확인에 필요한 검색어와 좌표를 처리합니다. OpenFreeMap은 선택 위치 주변의 수역 조회에 필요한 타일 주소·범위를 받습니다. 기상청과 국립해양조사원은 날씨·물때·수온 조회에 사용하는 격자 또는 관측소 코드와 조회 날짜·시간 등 요청 정보를 받습니다. 도감에서 외부 조회가 필요한 경우 국립수산과학원, 국립해양생물자원관, 위키미디어, GBIF, iNaturalist 등 데이터·이미지 제공 서비스에 어종명·학명·분류 식별자 또는 이미지 요청 정보가 전달될 수 있습니다. 이러한 조회는 계정 이메일·UID, 전체 출조 기록을 전달하지 않고 기능에 필요한 값으로 요청합니다.

외부 서비스에는 통신 과정에서 IP 주소, 브라우저·기기 정보, 요청 경로·시각 등이 전달될 수 있습니다. 제공업체가 자체 목적으로 개인정보를 받거나 처리하는지, 위탁 또는 법령상 제3자 제공에 해당하는지는 공급자와 통신 항목별로 확인해야 합니다. 제3자 제공이 필요한 경우에는 법령상 근거에 따라 처리하고, 해당하는 제공받는 자·목적·항목·보유기간과 동의 거부 효과를 알립니다. 사용자가 공유 메뉴에서 고른 앱은 사용자가 전송한 이미지를 받으며 그 이후의 처리는 해당 앱과 수신자의 설정 및 이용 방식에 따릅니다.

6. 개인정보의 국외 이전

Google의 공개 안내에 따르면 Firebase Authentication은 미국 데이터센터에서만 인증정보를 처리합니다. 앱 또는 계정 관리 웹에서 가입·로그인·재인증·비밀번호 관리 등 인증 기능을 사용할 때 이메일·비밀번호, 계정 식별자·인증에 필요한 정보, 접속 IP·브라우저 정보가 암호화된 네트워크 통신으로 전달됩니다. 처리 목적은 인증·계정 관리와 부정 이용 방지입니다. Google은 인증 IP 로그를 수 주간 보유하고, 기타 인증정보는 계정 삭제가 시작된 뒤 운영·백업 시스템에서 180일 이내에 제거한다고 안내합니다. 이 기간은 Firebase Authentication에 관한 안내입니다.

Firebase Authentication을 이용하지 않으려면 회원 인증이 없는 기능을 이용할 수 있습니다. 이 경우 계정 기능과 회원의 기록 저장·동기화를 이용할 수 없습니다. 기존 계정에 관한 처리 중단·탈퇴 등은 운영자에게 문의할 수 있습니다. 이미 전송된 정보의 처리 및 삭제는 관련 법령과 사업자의 처리 기한에 따릅니다.

계약 체결·이행에 필요한 국외 처리 위탁·보관을 근거로 삼을 경우 「개인정보 보호법」 제28조의8제1항제3호와 제2항에 따라 이전 항목, 국가·시기·방법, 이전받는 법인과 연락처, 이전받는 자의 목적과 보유·이용기간, 거부 방법·절차 및 효과를 모두 공개하거나 법령에서 정한 방법으로 알립니다. 별도의 국외 이전 동의가 필요한 경우에는 필요한 사항을 안내하고 동의를 받아야 합니다.

이 앱의 기본 Cloud Firestore 데이터베이스 저장 리전은 대한민국 서울(asia-northeast3)입니다. Firebase Hosting은 여러 국가의 서버에서 페이지를 제공할 수 있고, Google은 웹 요청의 접속 IP를 남용 방지와 사용량 분석 목적으로 수개월 보관한다고 안내합니다. 지도·도감 외부 서비스에서도 개인정보가 국외에서 처리되는지 확인이 필요합니다. 이전받는 실제 법인·연락처, 제품별 처리 국가·기간, 위탁과 국외 이전의 법적 근거는 공개 전에 확정해야 합니다.

7. 보유기간과 파기

계정·프로필 정보는 회원 서비스 제공에 필요할 때 보유하고 탈퇴 절차에 따라 정리합니다. 이용자가 기록이나 사진을 삭제하면 해당 기능이 관리하는 기기 자료를 정리합니다. 동기화한 기록의 서버 본문은 삭제 상태가 반영되면 최소 삭제 표식으로 대체됩니다. 삭제 표식에는 계정·기록 식별자, 상태·버전·변경 시각 및 처리 요청 식별자가 남을 수 있습니다. 중복 반영 방지용 동기화 처리 이력과 함께 삭제 반영·재시도 확인에 사용하며, 관리 기준과 보유기간을 공개 전에 확정해야 합니다.

앱에서 탈퇴하면 본인 확인 후 서버의 기록 본문·동기화 처리 이력·권한·프로필·닉네임과 인증 계정을 순차적으로 삭제하고 해당 기기의 기록·사진·계정 캐시·대기열·충돌 자료를 정리합니다. 네트워크가 끊기면 일부 정리가 다음 연결이나 실행 때 재개될 수 있습니다. 다른 기기는 연결되는 시점에 서버의 탈퇴 정보를 확인한 뒤 해당 계정의 앱 내부 자료를 정리합니다. 사용자가 별도로 보관한 갤러리 원본·내보낸 이미지·다른 앱의 사본은 해당 저장 위치에서 관리합니다.

웹 접수의 경우 운영자가 확인한 후 삭제를 진행합니다. 관련 자료와 인증 계정 삭제를 확인하면 웹 접수 문서를 정리합니다. 오래된 기기나 인증 상태가 탈퇴 계정의 데이터를 다시 만들지 못하도록 UID, 요청 상태·시각, 형식 버전을 담은 탈퇴 표식이 남습니다. 현재 표식은 자동 만료되지 않습니다. 보유기간과 관리자 파기 절차는 공개 전에 확정해야 합니다. 문의 메일의 보유기간과 일반 문의·웹 삭제 요청의 운영상 응답 및 처리 목표 기한도 미정입니다.

처리 목적을 달성하거나 보유기간이 경과한 개인정보는 지체 없이 파기합니다. 다른 법령에 따라 보존해야 하는 경우에는 해당 항목을 관련 법령에서 정한 기간 동안 다른 정보와 분리하여 보관한 뒤 파기합니다. 앱과 운영 시스템의 전자 파일·DB 항목은 각 저장소의 절차에 따라 복구 또는 재생이 어렵도록 파기합니다. 위탁 서비스의 백업은 제공업체의 삭제 주기에 따릅니다.
