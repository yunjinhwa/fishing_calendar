# 지도·기록 화면 정리

브랜치: `refactor/map-record-ui` · 대상: [추가 요구사항](pre-release-additional-requirements.md)의 U-01~U-05.

## 화면 변경

| 항목 | 변경 내용 |
| --- | --- |
| 지도 검색 결과 | 기본 글자 크기에서 약 4행이 보이는 최대 320px 목록으로 표시. 내부 스크롤로 전체 결과 선택 가능 |
| 검색·지도 유지 | 목록을 스크롤하거나 결과를 선택해도 지도 상태 유지. 새 검색 결과를 받으면 목록 맨 위로 이동 |
| 지도 설명 | 선택 위치의 저장 설명과 중복된 자동 판별 문구 제거. 위치 확인 중 표시·판별 재시도·자동/바다/민물 선택 유지 |
| 기록 작성 | 자동입력 완료 카드, 만조·간조 예보 카드, 긴 자동입력 설명과 출처·관측 시각 보조 문구 제거 |
| 좌표 입력 | 위도·경도 입력 카드와 지우기 버튼 제거. 전달받은 좌표는 내부 값으로 관리 |
| 개발용 플랜 버튼 | 기본 비노출. 명시적으로 허용한 디버그 실행에서만 로컬 무료/유료 전환 가능 |

긴 장소명·주소는 줄바꿈하고 큰 글자에서는 수역 선택 버튼을 세로로 배치한다. 검색 결과를 4개로 잘라 버리지 않는다.

물때·수온 선택 입력, 필수값 검증, 날씨·과거 관측·수온·물때 자동입력과 사용자가 수정하거나 지운 값의 보호는 유지한다. 출처·라이선스는 기존 앱 정보 메뉴에서 확인할 수 있다.

## 좌표 보존

- 지도·지도 상세에서 전달받은 좌표를 기록과 SQLite·Outbox에 저장한다.
- 기존 기록의 메모 등 다른 항목만 수정하면 원래 좌표를 유지한다. 최신 기록을 다시 불러올 때도 해당 기록의 장소·좌표를 함께 적용한다.
- 장소 이름만 입력한 새 기록은 좌표 없이 저장한다.
- 장소명을 다른 곳으로 바꾸면 이전 장소의 좌표를 새 이름에 붙이지 않는다. 원래 이름으로 되돌리면 원본 좌표와의 연결을 복원한다. 앞뒤 공백은 무시한다.
- 좌표의 쌍·범위·유한성 검증은 유지한다. UI가 숨겨져도 잘못된 전달 값으로 저장 검증을 우회하지 않는다.

좌표 모델·DB·서버 계약은 변경하지 않는다. 별도 DB 마이그레이션이나 Firebase 규칙 배포는 필요하지 않다.

## 개발용 버튼

내 정보의 플랜 정보·동기화/충돌 관리·오프라인·재시도 기능은 실제 사용자 기능으로 유지한다. 기존 내 정보 화면에는 별도의 테스트 버튼이 없었으며, 로컬 플랜 화면의 무료/유료 전환만 제한한다.

로컬 플랜 전환을 테스트해야 할 때는 다음 옵션으로 실행한다.

```powershell
flutter run --debug --dart-define=ENABLE_DEVELOPMENT_PLAN_CONTROLS=true
```

이 옵션은 로컬 개발 인증 모드에서 사용한다. Firebase 인증 계정의 플랜은 서버 entitlement를 따르며, 옵션을 켜도 로컬 전환으로 서버 권한을 바꿀 수 없다. 서버 플랜 새로고침은 유지한다. release/profile에서는 해당 옵션을 켜도 개발용 전환 버튼을 표시하지 않는다.

## 검증

기존 테스트를 제거된 UI 문구·입력란 대신 실제 입력값과 저장된 데이터로 확인하도록 갱신했다.

- 지도: 결과 4행 높이, 마지막 결과 선택, 반복 검색 시 스크롤 복원, 지도 재생성 방지, 큰 글자·긴 주소, 수역 판별 재시도와 수동 전환.
- 기록: 좌표 입력 UI 비노출, SQLite·Outbox 좌표 보존과 이름 변경 시 분리, 작성 취소, 잘못된 전달 좌표 거부.
- 자동입력: 날씨·물때·수온·과거 관측의 장소/좌표/시간 일치 검사, 날짜 변경, 수동 수정·지우기와 저장 결과.
- 플랜: 개발용 버튼 기본 비노출·디버그 허용, 서버 새로고침과 권한 보호, 기존 내 정보 메뉴 접근.

2026-11-16 **전체 Flutter 테스트 1,496개와 정적 분석이 통과**했다. 변경 Dart 파일 12개의 포맷 검사와 `git diff --check`도 통과했다. 실제 기기 조작과 최종 빌드·배포는 실행하지 않았다.

## 실제 기기 확인

1. 결과가 여러 개인 장소를 검색한다. 목록 안에서 아래 결과까지 내려 선택하고, 새 검색 후 맨 위 결과부터 보이는지 확인한다.
2. 휴대전화 글자 크기를 크게 설정하고 긴 장소명·주소를 검색한다. 목록과 수역 선택 버튼이 잘리거나 넘치지 않아야 한다.
3. 지도에서 기록 작성으로 이동한다. 예보 카드·좌표 입력·긴 안내가 사라지고, 자동입력된 값은 남아 있어야 한다. 물때·수온을 비워도 필수값이 있으면 저장되어야 한다.
4. 지도에서 만든 기록을 저장하고 메모만 수정한다. 상세의 좌표가 유지되는지 확인한다. 장소명을 다른 곳으로 바꿔 저장하면 이전 좌표가 남지 않아야 한다.
5. 기본 실행의 플랜 화면에서는 무료/유료 전환 버튼이 보이지 않아야 한다. 동기화·충돌 관리와 실제 계정의 서버 플랜 새로고침은 계속 사용할 수 있어야 한다.
