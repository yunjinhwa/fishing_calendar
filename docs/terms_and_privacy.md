# 낚시 캘린더 약관과 개인정보 처리방침

운영자 피클의 개인정보·서비스 문의 창구는 **www139455@naver.com**이다. 두 문서는 **시행일 미정인 공개 전 검토본**이다. 시행일은 운영자가 이용자에게 새 문서를 적용하기 시작하는 날짜다. 최초 출시라면 가입을 받기 전에 본문을 게시하고 서비스 개시일에 맞춰 시행할 수 있다. 기존 회원에게 변경을 적용할 때는 공지 및 필요한 동의 절차도 고려한다.

회원가입의 **내용 보기**와 **내정보 → 약관 및 정책**에서 앱에 포함한 원문을 오프라인으로 읽을 수 있다. 앱에서 원문을 여는 것만으로 동의가 기록되지는 않는다. 웹 페이지도 같은 파일에서 생성한다. [개인정보 처리방침 원문](../assets/legal/privacy.txt) · [이용약관 원문](../assets/legal/terms.txt)

## 출시 전에 결정할 사항

## 가입 화면과 연령 선택

가입 화면은 이용자가 직접 고른 연령대를 기준으로 동작한다. Firebase 가입 요청에는 선택값이 포함되지 않으며, Firebase 서버가 실제 연령을 확인할 수 없다. 가입 연령 정책과 별도로 비회원의 지도·도감 사용 중 개인정보 처리 요건을 점검한다.

향후 만 14세 미만 가입을 열기로 하면 법정대리인 자격과 필요한 동의를 확인하는 방법, 계정 생성 전 확인 결과 검증, 동의 증빙의 보관·파기 절차를 마련한다. [개인정보 보호법 제22조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1020398521)

## 법적 근거와 공급자 자료

- 헌법 제17조의 사생활 보호 원칙에 따라 위치·사진·메모를 이용자가 선택할 수 있게 설명했다. 구체적인 처리 목적·최소 수집·파기, 처리위탁, 안전조치, 방침 공개 및 이용자의 권리는 개인정보 보호법 제15·16·21·26·29·30조와 제35~38조 등을 참고했다. [대한민국헌법 제17조](https://www.law.go.kr/법령/대한민국헌법/제17조) · [개인정보 보호법](https://www.law.go.kr/lsInfoP.do?lsId=011357) · [시행령 제31조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029331787) · [개인정보보호위원회 처리방침 작성지침 2026.4](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS217&mCode=G010030030&nttId=12018)

[개인정보 보호법 제22조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1020398521) · [시행령 제17조의2](https://www.law.go.kr/법령/개인정보보호법시행령/제17조의2) · [위치정보법 제25조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1032065439)

## 미리보기와 정식 공개

미리보기 명령은 두 원문을 HTML로 만들고 비밀번호 재설정·계정 삭제 페이지와 함께 별도 폴더에 준비한다. 프로젝트 루트에서 다음 명령을 실행하고 브라우저로 http://127.0.0.1:8085/privacy/ 또는 http://127.0.0.1:8085/terms/ 를 연다.

```powershell
node tool/prepare_password_reset_web.mjs --preview-legal
python -m http.server 8085 --bind 127.0.0.1 --directory .dart_tool/auth_web_preview
```

운영 공개 전에는 본문의 미확정 내용을 먼저 해결한다. 두 문서 머리말의 검토본 표시를 지우고 확정한 날짜를 각각 `시행일 YYYY-MM-DD`로 표시한다. 일반 준비 명령 `node tool/prepare_password_reset_web.mjs`는 두 문서가 이 형식을 갖추면 기존 Hosting 산출물에 함께 넣는다. 저장소에서 검토 중인 현재 버전으로는 기존 웹 기능만 운영 배포용 폴더에 준비된다. 미리보기는 외부 배포를 수행하지 않는다.

최초 게시 후 다음 개정을 검토하는 동안에는 이전 시행본이 계속 제공되도록 **마지막 공개본**을 기준으로 운영 웹을 준비한다. Firebase Hosting 배포는 사이트 전체를 교체한다. 새 정책의 시행일, 두 공개 경로, 기존 비밀번호 재설정·웹 탈퇴 경로를 함께 확인한다. 앱에는 원문이 번들되므로 앱 업데이트와 웹 게시 일정을 맞추고 기존 앱 버전을 사용하는 회원에게도 변경을 알린다.

```powershell
flutter test --no-pub test/policy_documents_test.dart
node --test tool/legal_web_test.mjs tool/account_deletion_web_test.mjs tool/password_reset_web_test.mjs
```
