# 지도 바다·민물 구분과 통합 정보 카드

선택 좌표를 실제 지리 데이터와 대조해 바다·민물·내륙을 구분한다. 바닷가 검색 좌표가 마을·산책로 같은 육지에 잡히는 경우도 해안 거리로 처리한다. 가까운 조위 관측소나 주소 유무로 바다를 추정하지 않는다.

## 자동 판별

- [OpenFreeMap](https://openfreemap.org/quick_start/)의 동적 TileJSON `https://tiles.openfreemap.org/planet`에서 현재 버전의 타일 주소를 확인한다. 새 API 키나 유료 서비스 설정은 필요하지 않다.
- [OpenMapTiles water 레이어](https://openmaptiles.org/schema/#water)의 상세 줌 14 폴리곤과 선택 좌표를 대조한다. `ocean` 내부는 바다로, 호수·강·연못 내부는 민물로 분류한다. 나머지 육지는 내륙으로 구분해 실제 민물과 섞지 않는다.
- 육지라도 실제 바다 영역까지 거리가 500m 이내면 해안으로 취급해 바다 정보를 제공한다. 이 거리는 앱의 표시 정책이며 장소 이름이나 조위 관측소 거리로 계산하지 않는다. 강·호수 안의 좌표는 바다와 가까워도 민물을 유지하고, 육지에서 민물 경계가 바다보다 가깝거나 같은 경우에도 바다 정보를 표시하지 않는다.
- 해안 거리가 인접 타일까지 걸치는 경우 그 타일도 확인한다. 한 위치에서 확인할 타일은 최대 3×3개로 제한하고 기존 타일 캐시와 진행 중 요청을 공유한다. 필요한 타일을 받지 못하면 바다로 추정하지 않고 판별 불가로 남긴다.
- 섬과 폴리곤의 구멍을 처리한다. 경계·불명확한 도크·손상된 형상·지원 범위 밖·조회 실패는 판별 불가로 남긴다. 주소 검색 결과가 없다고 바다로 간주하지 않는다.
- 요청은 10초로 제한한다. 메타데이터와 디코딩한 타일은 메모리에 하루 동안 캐시하고 최대 64개 타일을 보관한다. 같은 타일의 동시 요청을 공유하며 타일 하나는 2MiB로 제한한다.
- 새 위치의 자동 판별은 인터넷 연결이 필요하다. 오프라인에서 바다 여부를 확인할 수 없는 위치는 바다 전용 정보를 표시하지 않는다. `바다 / 민물`을 직접 선택해 해안 경계·항구 육상 지점 등을 수정할 수 있다.
- 선택 위치 변경·수동 변경·지도 탭 비활성화 이후 도착한 응답은 무시한다. 위치를 바꾸면 수동 지정도 초기화한다.

## 화면과 조회 제한

`날씨·낚시 정보` 카드 하나에 날씨·기온을 표시하고, 바다·해안으로 판별된 위치에서 물때·수온·만조·간조를 추가한다. 민물·내륙과 판별 불가 위치에서는 바다 전용 값과 조석 요청을 차단한다. 지도 상세 및 지도에서 여는 기록의 자동 물때에도 같은 제한을 적용한다.

값이 없으면 `제공되지 않음`으로 표시한다. [관측 수온](water_temperature_api_setup.md)은 주변 관측소의 최신 실측값을 별도로 조회하며 자료가 없으면 임의의 수온을 만들지 않는다. 출처·예보 격자·발표 기준·거리·음력·계산식과 긴 수동 입력 안내는 결과 카드에서 제거했다. 관측 수온의 지점·시각은 실제 관측값임을 구분하는 정보로 표시한다. 법적 고지는 [데이터 고지](../third_party/open_map_water_NOTICE.txt)와 앱 라이선스에 보존한다.

## 확인한 실제 조회 (2026-11-03)

| 위치 | 위도, 경도 | 결과 |
| --- | --- | --- |
| 한강 여의도 북쪽 | 37.535, 126.934 | 민물 |
| 흰여울문화마을 대표 좌표 | 35.0798897489113, 129.043539607828 | 바다·해안 (좌표 자체는 육지) |
| 시화호 | 37.2994, 126.6679 | 민물 |
| 팔미도 인근 바다 | 37.312, 126.508 | 바다 |
| 서울시청 | 37.5665, 126.978 | 내륙 |

흰여울문화마을은 [한국관광공사 안내](https://korean.visitkorea.or.kr/detail/ms_detail.do?cotid=91c9d21b-50cc-4875-a717-c4fff63e3372)의 공개 상세 조회 응답 `mapY/mapX`를 사용했다. 카카오 검색 결과의 좌표와 완전히 같다고 가정하지 않는다. 같은 좌표의 엄격한 바다 영역 내부 검사 결과는 내륙이지만, 500m 해안 정책을 적용하면 바다 정보를 제공한다. 예전에 사용한 한강 인근 `37.528, 126.934`는 육지이므로 실제 강 내부 좌표로 보완했다.

해안선과 항만 시설이 변할 수 있으므로 자동 판별 결과는 선택 버튼으로 수정할 수 있다. 데이터가 없거나 판별되지 않으면 바다 정보는 표시하지 않는다.

## 기기 테스트

1. 기존 실행을 종료하고 세 로컬 설정을 포함한 명령으로 다시 실행한다. 새 Dart 패키지가 추가되어 최초 실행에서 패키지 설치가 진행될 수 있다.
2. 한강·시화호에서 날씨·기온은 표시되고 물때·수온·만조·간조는 표시되지 않는지 확인한다.
3. 실제 바다 위치와 흰여울문화마을 같은 해안 지점을 선택해 네 항목과 만조·간조 행이 한 카드에 표시되는지 확인한다. 수온처럼 없는 값은 `제공되지 않음`이어야 한다. 서울시청 같은 내륙은 민물과 구분해 `내륙`으로 표시되어야 한다.
4. `자동 / 바다 / 민물`을 바꾸고, 위치도 빠르게 변경한다. 이전 바다 예보가 민물 화면을 덮어쓰면 안 된다.
5. 지도 상세에 같은 값을 표시하는지 확인한다. 작은 화면과 큰 글씨에서 카드와 선택 버튼이 잘리지 않아야 한다.

## 개발 검증 (2026-11-03)

- 전체 Flutter 테스트 628개 통과, 전체 정적 분석 오류 없음
- 지리 판별 서비스 테스트 30개: 바다·호수·강·육지·섬·경계, 500m 해안 거리, 인접 타일·날짜변경선·민물 둔치·조회 실패·캐시·동시 요청 검증
- 민물에서 조석 요청 금지, 늦은 지리·조석 응답 차단, 직접 선택과 기록 자동 입력 제한 검증
- 320px 화면·글씨 2배 크기 테스트와 바다·민물·데이터 없음 화면 렌더링 확인
- Android 실제 기기 화면과 위치 선택은 위 절차로 사용자가 최종 확인한다.
