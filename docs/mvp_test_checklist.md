# Fishing Build MVP 테스트 체크리스트

## 1. 앱 실행 / 기본 이동

- [ ] 앱 실행 시 로그인 선택 화면이 표시된다.
- [ ] 비회원으로 시작하기를 누르면 메인 화면으로 이동한다.
- [ ] 하단 탭이 표시된다.
- [ ] 비회원은 지도와 도감을 이용할 수 있다.
- [ ] 비회원이 캘린더 / 기록 / 내정보 탭을 누르면 로그인 안내가 표시된다.

## 2. 인증 mock 화면

- [ ] 로그인 버튼을 누르면 로그인 화면으로 이동한다.
- [ ] 회원가입 버튼을 누르면 회원가입 화면으로 이동한다.
- [ ] 로그인 필수값이 비어 있으면 안내 메시지가 표시된다.
- [ ] 로그인 이메일 형식이 올바르지 않으면 안내 메시지가 표시된다.
- [ ] 가입되지 않은 이메일 또는 잘못된 비밀번호로 로그인할 수 없다.
- [ ] 이전 버전에서 복원된 회원은 기존 로그인 상태에서 비밀번호를 설정하기 전에는 로그아웃할 수 없다.
- [ ] 비밀번호가 없는 이전 계정은 로그인 화면에 입력한 임의 비밀번호를 새 비밀번호로 저장하지 않는다.
- [ ] 회원가입 필수값이 비어 있으면 안내 메시지가 표시된다.
- [ ] 회원가입 비밀번호는 8자 이상이며 영문과 숫자를 포함해야 한다.
- [ ] 회원가입 닉네임은 2자 이상 20자 이하이어야 한다.
- [ ] 로그인 성공 mock 처리 후 메인 화면으로 이동한다.
- [ ] 회원가입 성공 mock 처리 후 메인 화면으로 이동한다.
- [ ] 이미 가입된 이메일로 회원가입하면 중복 안내가 표시되고 기존 플랜이 유지된다.
- [ ] 회원가입 후 무료 회원 상태가 적용된다.
- [ ] 로그인 상태 유지 해제 후 앱을 다시 시작하면 로그인 선택 화면이 표시된다.
- [ ] 플랜 정보에서 무료 회원과 유료 회원을 전환할 수 있다.
- [ ] 변경한 플랜은 앱 재시작과 다음 로그인 후에도 유지된다.
- [ ] 로그아웃 후 다른 계정으로 로그인하면 이전 계정의 기록과 Outbox가 표시되지 않는다.
- [ ] 계정 소유자가 없는 이전 버전 기록은 자동 귀속되지 않고 이전 기기 기록 보관함에 남는다.
- [ ] 이전 기기 기록은 소유권 경고를 확인하고 가져오기를 선택한 뒤에만 현재 계정에 추가된다.
- [ ] 기존 기록이 있는 무료 회원의 유료 전환 시 기록이 업로드 대기열에 등록된다.
- [ ] 기존 기록 이전이 끝나기 전에는 클라우드 동기화가 제한된다.
- [ ] 대기 또는 실패한 업로드가 있으면 무료 플랜 전환이 제한된다.
- [ ] 무료 회원에게 동기화 기능 대신 유료 플랜 안내가 표시된다.
- [ ] 유료 회원은 동기화 / 충돌 관리 화면으로 이동할 수 있다.

## 3. 출조 기록 작성

- [ ] 기록 탭에서 출조 기록 작성 화면으로 이동한다.
- [ ] 위치를 입력하지 않으면 안내 메시지가 표시된다.
- [ ] 낚시 장르를 선택하지 않으면 안내 메시지가 표시된다.
- [ ] 종료 시간이 시작 시간보다 빠르거나 같으면 안내 메시지가 표시된다.
- [ ] 물때 / 날씨 / 기온 / 수온을 입력하지 않으면 안내 메시지가 표시된다.
- [ ] 기온/수온에 숫자가 아닌 값을 입력하면 안내 메시지가 표시된다.
- [ ] 조과 추가 버튼을 누르면 조과 입력 카드가 추가된다.
- [ ] 조과 삭제 버튼을 누르면 조과 입력 카드가 삭제된다.
- [ ] 조과가 1개만 남았을 때 삭제하면 안내 메시지가 표시된다.
- [ ] 어종 없이 크기 또는 무게만 입력하면 안내 메시지가 표시된다.
- [ ] 정상 입력 후 저장하면 기록 탭 화면으로 돌아간다.

## 4. 캘린더 / 날짜별 기록

- [ ] 저장한 기록이 캘린더 날짜 칸에 표시된다.
- [ ] 날짜를 선택하면 날짜별 기록 목록 화면으로 이동한다.
- [ ] 기록이 있는 날짜에는 기록 목록이 표시된다.
- [ ] 기록이 없는 날짜에는 빈 상태 화면이 표시된다.
- [ ] 날짜별 기록 목록에서 기록을 누르면 상세 화면으로 이동한다.
- [ ] 상세 화면에서 기록을 삭제할 수 있다.
- [ ] 삭제 후 날짜별 기록 목록에서 기록이 사라진다.
- [ ] 날짜별 기록 목록에서 뒤로가기 시 캘린더가 갱신된다.

## 5. 기록 검색 / 필터

- [ ] 기록 탭에서 기록 검색 화면으로 이동한다.
- [ ] 장소 검색이 동작한다.
- [ ] 어종 검색이 동작한다.
- [ ] 메모 검색이 동작한다.
- [ ] 낚시 장르 필터가 동작한다.
- [ ] 시작일/종료일 기간 필터가 동작한다.
- [ ] 시작일/종료일 개별 초기화가 동작한다.
- [ ] 최신순/오래된순 정렬이 동작한다.
- [ ] 검색 결과 개수가 표시된다.
- [ ] 검색 결과가 없으면 빈 상태 화면이 표시된다.
- [ ] 검색 결과를 누르면 기록 상세 화면으로 이동한다.

## 6. 지도 / 외부 데이터 mock

- [ ] 지도 탭으로 이동한다.
- [ ] 위치 검색 시 선택 위치가 변경된다.
- [ ] 외부 데이터 조회 로딩 상태가 표시된다.
- [ ] 외부 데이터 조회 성공 시 날씨/물때/수온이 표시된다.
- [ ] `실패`가 포함된 위치를 검색하면 실패 상태가 표시된다.
- [ ] 실패 상태에서 기록 작성 시 위치만 자동 입력된다.
- [ ] 정상 상태에서 기록 작성 시 위치/물때/날씨/기온/수온이 자동 입력된다.
- [ ] 위치 대체 입력 화면으로 이동할 수 있다.
- [ ] 추천 장소 선택 시 지도 화면의 위치가 변경된다.
- [ ] 지도 상세 화면으로 이동할 수 있다.
- [ ] 과거 정보 조회 화면으로 이동할 수 있다.

## 7. 어류도감

- [ ] 도감 탭으로 이동한다.
- [ ] 어류도감 목록이 표시된다.
- [ ] 어종 검색이 동작한다.
- [ ] 전체 / 바다 / 민물 / 금어기 필터가 동작한다.
- [ ] 검색 결과가 없으면 빈 상태 화면이 표시된다.
- [ ] 어종을 누르면 상세 화면으로 이동한다.
- [ ] 상세 화면에 기본 정보와 금어기 정보가 표시된다.
- [ ] 이 어종으로 기록 작성하기를 누르면 기록 작성 화면으로 이동한다.
- [ ] 선택한 어종이 조과 1에 자동 입력된다.

## 8. 개인 기록어

- [ ] 내정보에서 내 기록어 화면으로 이동한다.
- [ ] 기록어가 없으면 빈 상태 화면이 표시된다.
- [ ] 어종과 크기 또는 무게가 있는 기록을 저장하면 기록어가 표시된다.
- [ ] 크기순 정렬이 동작한다.
- [ ] 무게순 정렬이 동작한다.
- [ ] 기록어 항목을 누르면 상세 화면으로 이동한다.
- [ ] 공유 이미지 미리보기 버튼을 누르면 안내 메시지가 표시된다.

## 9. 오프라인 / Outbox / 충돌 mock

- [ ] 비회원의 오프라인 진입 시 로그인 안내 화면이 표시된다.
- [ ] 무료 회원의 오프라인 안내에서 로컬 기록 작성 / 조회 정책이 표시된다.
- [ ] 유료 회원의 오프라인 안내에서 캐시 / Outbox 정책이 표시된다.
- [ ] 내정보에는 현재 플랜에 맞는 오프라인 진입 항목만 표시된다.
- [ ] 무료 회원은 Outbox와 동기화 / 충돌 내용을 열 수 없다.
- [ ] 유료 회원 화면에서 대기열 보기로 이동한다.
- [ ] outbox 대기/성공/실패 상태가 표시된다.
- [ ] 유료 회원의 기록 생성 / 수정 / 삭제 요청이 같은 기록 ID로 outbox에 저장된다.
- [ ] Outbox에는 요청 당시 기록 payload와 계정 식별자가 저장된다.
- [ ] 앱을 다시 실행해도 미전송 Outbox 항목이 유지된다.
- [ ] Outbox 저장 직후 앱이 종료되어도 재실행 시 로컬 기록이 payload와 일치하도록 복구된다.
- [ ] 중단된 플랜 전환을 다시 실행하면 기존 마이그레이션 payload가 최신 기록 값으로 갱신된다.
- [ ] 빈 Outbox 화면을 열어도 테스트용 항목이 자동 생성되지 않는다.
- [ ] 실패 항목 재시도 버튼이 동작한다.
- [ ] 전체 전송 처리 버튼이 동작한다.
- [ ] 완료 항목 정리 버튼이 동작한다.
- [ ] 기록 이전 중에는 완료된 이전 항목을 정리해도 이전 완료 판정이 고착되지 않는다.
- [ ] 내정보에서 동기화/충돌 관리 화면으로 이동한다.
- [ ] 충돌 목록이 표시된다.
- [ ] 충돌 상세 화면으로 이동한다.
- [ ] 내 변경 적용 / 상대 변경 적용 / 직접 병합 처리가 동작한다.
- [ ] 충돌 해결 후 미해결 충돌 수가 갱신된다.

## 10. 최종 점검

- [ ] `flutter analyze` 결과가 `No issues found!`이다.
- [ ] 앱 실행 중 빨간 overflow 메시지가 표시되지 않는다.
- [ ] 주요 화면에서 뒤로가기 동작이 자연스럽다.
- [ ] 사용자에게 보이는 문구에 불필요한 개발 브랜치명이나 내부 구현명이 노출되지 않는다.
- [ ] GitHub PR에 작업 범위와 확인 내용이 정리되어 있다.
