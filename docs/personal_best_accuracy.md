# 내 기록어 집계와 근거 표시

같은 어종의 최고 크기와 최고 무게를 독립적으로 계산한다. 예를 들어 50cm·1,000g과 40cm·2,000g의 두 조과가 있으면 최고 크기는 50cm, 최고 무게는 2,000g이다. 두 값을 한 마리의 조과로 합치지 않고 각각의 원본 조과·출조 기록을 보존한다.

## 집계 기준

- 이름 앞뒤 공백을 제거한 같은 어종끼리 묶는다. 별칭이나 다른 학명을 임의로 같은 어종으로 합치지 않는다.
- 크기는 유한한 양수, 무게는 양수만 인정한다. 누락·0·음수·NaN·무한대는 최고 기록의 근거로 사용하지 않는다.
- 두 측정값이 모두 없는 조과는 기록어에서 제외한다. 한쪽만 있으면 해당 측정값을 사용하고 다른 쪽은 `-`로 표시한다.
- 측정값이 같으면 출조 시작 시각이 더 최근인 기록을 선택한다. 시각도 같으면 기록 ID 오름차순, 같은 기록 안에서는 조과 순서 오름차순으로 결정한다. 조회 순서가 달라져도 근거가 흔들리지 않는다.
- 크기순·무게순은 정렬과 선택된 근거만 바꾼다. 최고 크기·최고 무게 자체는 바뀌지 않는다. 해당 측정값이 없는 어종은 정렬의 뒤에 배치하며 같은 값의 어종은 이름순으로 정렬한다.
- 이름순은 어종명 오름차순(가나다순)으로 정렬한다. 최고 값은 유지하며, 사진·날짜·장소는 크기 기록을 우선하고 크기가 없으면 무게 기록을 표시한다.

기록어 전용 테이블이나 서버 사본은 추가하지 않는다. 현재 계정의 출조 기록에서 계산하며, 수정·삭제·동기화 후 최신 기록으로 다시 계산한다.

## 화면과 사진

화면 상단에서 어종명의 일부를 입력해 검색한다. 앞뒤 공백과 영문 대소문자는 구분하지 않으며, 선택한 크기순·무게순·이름순을 검색 결과에도 적용한다. 검색어를 지우면 전체 기록어를 다시 표시한다. 검색은 이미 집계한 목록에서 수행하므로 입력할 때마다 DB나 Firestore를 추가 조회하지 않는다. 계정이 바뀌면 검색어를 초기화한다.

목록의 날짜·장소·사진에는 어떤 기준의 기록인지 함께 표시한다. 상세 화면에서는 최고 크기와 최고 무게의 근거를 따로 표시하고, 선택한 기준에 맞는 출조 정보와 사진을 보여 준다. 선택한 측정값이 없으면 실제로 존재하는 다른 기준을 명확히 표시한다.

사진은 해당 출조 기록에 연결된 기기 내 사진이다. 현재 모델에는 조과별 사진 연결이 없으므로 특정 물고기의 사진이라고 추정하지 않고 `출조 사진`으로 표시한다. 다른 기기로 사진을 전송하거나 Firebase Storage를 사용하지 않는다. 사진이 없거나 파일을 읽을 수 없으면 대체 아이콘을 표시한다.

상세 화면이 열린 상태에서 원본 기록을 수정·삭제하거나 동기화로 바뀌어도 근거를 다시 찾는다. 해당 어종의 유효한 측정값이 모두 없어지면 삭제·미측정 안내를 표시한다. 계정 전환·로그아웃·탈퇴 대기 상태에서는 이전 계정의 상세 내용을 계속 표시하지 않는다. 비회원은 기록어 데이터를 조회하지 않는다.

목록 집계는 기록 변경·정렬 변경 시 수행하고 일반 화면 빌드에서 반복하지 않는다. 사진은 표시 크기에 맞춰 디코딩해 원본 사진의 큰 해상도를 그대로 메모리에 올리지 않는다.

## 유료 과거 기록과 오프라인

기존 `RecordHistoryScope`와 유료 캐시 정책을 사용한다. 온라인 유료 회원은 화면 진입 시 전체 서버 이력을 읽고, 목록·상세를 보고 있는 동안 31일 이전 기록도 유지한다. 정렬·기준 전환 때문에 서버를 다시 읽지 않는다. 화면 종료 후에는 기존 캐시 보관 정책을 다시 적용한다.

오프라인에서는 기기에 있는 기록만으로 집계하며 기존 안내를 표시한다. 아직 기기에 없는 과거 기록까지 최고 기록으로 확정하지 않는다. 연결 복구·조회 재시도·계정 변경은 기존 전체 이력 조회의 세션 검사와 재시도 정책을 따른다. 무료 회원은 서버 이력을 추가로 조회하지 않는다.

## 자동 검증

전체 Flutter 테스트 1,167개 통과, 전체 코드 분석 이상 없음. 기록어 관련 테스트 20개는 서로 다른 조과의 최고 값·사진·근거 연결, 누락/잘못된 측정값, 동률·정렬의 결정성, 수정·삭제, 비회원·계정 변경·로그아웃, 31일 이전 최고 기록과 오프라인 화면 보관을 검증한다. 실제 기기 화면 확인은 아래 절차로 별도 수행한다.

## 실제 기기 확인

1. 같은 어종으로 50cm·1,000g과 40cm·2,000g 기록을 서로 다른 날짜·장소·사진으로 저장한다. 목록의 최고 값이 50cm·2,000g으로 유지되고 정렬 기준에 따라 근거 기록이 바뀌는지 확인한다.
2. 상세에서 크기 기록·무게 기록을 전환한다. 각 최고 값의 근거와 선택된 출조 사진·날짜·장소가 일치해야 한다. 두 조과가 같은 출조에 들어 있어도 각각의 조과 순서를 구분해야 한다.
3. 측정값이 없는 어종은 기록어에 나타나지 않아야 한다. 크기 또는 무게 한쪽만 입력한 어종은 나머지 값이 `-`로 표시되어야 한다.
4. 최고 기록을 수정·삭제한다. 다음 최고 기록으로 갱신되고 해당 어종의 마지막 측정 기록까지 삭제하면 목록에서 사라지며 열린 상세에는 안내가 나와야 한다.
5. 온라인 유료 계정에서 31일 이전의 더 큰 기록도 표시되는지 확인한다. 상세에 들어갔다 돌아와도 유지되어야 하며 오프라인에서는 저장된 기록만 표시한다.
6. 사진이 없는 다른 기기에서도 숫자·날짜·장소는 유지되고 사진만 대체 표시되어야 한다. 로그아웃·계정 전환 후 이전 상세가 노출되지 않아야 한다.
