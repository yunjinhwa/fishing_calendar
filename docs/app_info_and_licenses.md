# 앱 정보와 출처·라이선스

내정보의 `앱 정보`에서 설치한 앱의 버전·빌드 번호와 다음 두 메뉴를 확인한다.

- `API·데이터·이미지 출처`: 자료별 제공기관·제작자와 라이선스.
- `오픈소스 라이선스`: Flutter·패키지의 라이선스, 포함 자료의 고지문과 개별 어류 자료의 필수 저작권 표시.

일반 출처 상세는 `제공기관·제작자`와 `라이선스`만 표시한다. 제공기관·제작자에서 공식 출처를, 라이선스에서 해당 원문을 열 수 있다. 사용 내용·이용조건 요약·일반 안내는 제거했다. 별도의 어종별 사진·정보 출처 메뉴와 검색·상세 화면도 제거했다.

버전은 설치된 앱의 패키지 정보에서 읽는다. 빌드 번호가 있으면 `버전 (빌드 번호)`로 표시하며, `pubspec.yaml` 기본값과 실제 설치본의 빌드 설정은 다를 수 있다. 정보를 읽지 못하면 다시 시도할 수 있고 출처·라이선스 메뉴는 계속 사용할 수 있다.

## 포함한 출처

[app_source_catalog.dart](../lib/data/app_info/app_source_catalog.dart)에 공개 출처 29개를 보존한다. 정적 목록 열람은 인증키·사용자 기록을 읽거나 외부 서비스에 연결하지 않는다. 연결 주소는 공식 문서·원문·정책 페이지이며 인증이 필요한 API 요청 주소가 아니다.

| 구분 | 출처 |
|---|---|
| 계정·동기화 | Google Firebase Authentication, Cloud Firestore |
| 지도·위치 | 카카오 지도·장소·주소 검색, 기기 운영체제·geolocator |
| 수역 지리 자료 | OpenFreeMap, OpenMapTiles, OpenStreetMap 기여자 |
| 날씨 | 기상청 초단기예보, ASOS 시간자료, 과거 지상관측 지점정보 |
| 바다 | 국립해양조사원 조석예보·예보 지점·기준항, 실측 수온·조위관측소 목록 |
| 음력·물때 | klc·go-klc 기여자, 한국천문연구원 달력 기준, 바다타임 물때표 명칭 기준 |
| 어류 정보·사진 | 국립수산과학원, Wikidata, 한국어·영어 위키백과, 한국어 위키문헌·글로벌 세계 대백과사전, Wikimedia Commons, MBRIS, GBIF·Catalogue of Life XR, iNaturalist |
| 공유 배경 | 앱 제작 과정에서 AI 도구로 생성한 장식 이미지 |

기본 서비스에서 호출하지 않는 NARIS와 사용하지 않는 Firebase Storage는 활성 출처로 표시하지 않는다. 공유 배경의 제작 근거는 [share_record_background.md](share_record_background.md)에 있으며, 외부 작가나 공개 라이선스를 임의로 붙이지 않는다.

## 저작권 고지와 오프라인 동작

어종별 출처 메뉴를 제거해도 사진·설명에 요구되는 개별 저작자·원문·라이선스와 번역·요약 등 변경 표시는 보존한다. `오픈소스 라이선스`의 `어류 자료 저작권 고지` 문서로 모아서 제공한다. 제공기관 이름만으로 개별 사진 저작자의 출처 표시를 대체하지 않는다.

고지는 앱에 포함된 `fish_catalog.json`, `fish_enrichment.json`, 검수된 사진·번역 보완 자료 및 기기에 이미 저장된 공개 도감 캐시에서 구성한다. 크기·서식지에 주 설명과 별개인 근거가 있으면 각 근거를 유지하고, 다른 사진이나 설명의 출처를 섞지 않는다. 저장되지 않은 저작자·라이선스는 추측하지 않는다. 이 과정에서 도감 목록·상세·썸네일·이미지 API를 새로 호출하거나 낚시 기록을 읽지 않는다.

사진에는 Commons 파일별 조건, iNaturalist의 선택 사진별 조건, 국립수산과학원 사진별 공공누리 표시가 각각 적용된다. 설명에 적용된 라이선스가 사진 전체에 자동 적용되는 것은 아니다. 이번 변경은 출처 표시 간소화이며 어류 정보 수집·보강을 추가하지 않는다.

기존 Flutter 라이선스 등록을 유지하면서 다음 고지문도 보존한다.

- [klc_LICENSE.txt](../third_party/klc_LICENSE.txt): 한국 음력 자료의 저작권·MIT 전문.
- [open_map_water_NOTICE.txt](../third_party/open_map_water_NOTICE.txt): 수역 지리 자료와 OpenStreetMap ODbL 출처.
- [fish_encyclopedia_NOTICE.txt](../third_party/fish_encyclopedia_NOTICE.txt): 어류 제공처와 개별 이용조건 보존 안내.

본문은 오프라인에서도 읽을 수 있다. 외부 링크는 사용자가 눌렀을 때만 브라우저 등 외부 앱으로 열며, 인터넷이 없으면 브라우저에서 연결 실패가 표시될 수 있다. 외부 앱을 실행하지 못한 경우 앱에 실패 안내를 표시한다.

## 수동 확인

`package_info_plus`, `url_launcher` 플러그인이 포함되므로 핫 리로드 대신 앱을 다시 빌드·실행한 뒤 확인한다. 별도의 인증키 설정이나 Firebase 규칙 배포는 필요하지 않다.

1. `내정보 → 앱 정보`에서 버전·빌드 번호와 두 메뉴가 표시되고, 어종별 사진·정보 출처 메뉴가 사라졌는지 확인한다.
2. `API·데이터·이미지 출처`에서 각 항목을 연다. 제공기관·제작자와 라이선스만 보이고 사용 내용·이용조건·안내 설명이 남아 있지 않아야 한다.
3. 제공기관과 라이선스 링크를 눌러 해당 공개 원문이 열리는지 확인한다. 표시·연결 주소에 인증키, 사용자 이메일·식별자, 낚시 기록이 없어야 한다.
4. 네트워크를 끄고 출처 목록과 오픈소스 라이선스를 읽는다. 출처 열람만으로 도감 API나 사진 다운로드가 실행되지 않아야 한다.
5. `오픈소스 라이선스 → 어류 자료 저작권 고지`에서 사진의 개별 저작자·원문·라이선스, 설명의 번역·요약과 원문 개정판, 별도 크기·서식지 근거가 보존되는지 확인한다.
6. 오픈소스 라이선스의 기존 세 고지문을 확인하고 반복 진입 시 중복 고지가 생기지 않는지 확인한다.
7. 작은 화면·큰 글자에서도 긴 제공기관·저작자명과 라이선스 본문을 읽을 수 있는지 확인한다.

## 검증

2026-11-09, Flutter 3.41.9 / Dart 3.11.5에서 간소화한 화면·출처·저작권 고지와 기존 약관·탈퇴 화면의 관련 테스트 47개가 통과했다. 제공기관·라이선스 링크, 제거한 메뉴·설명의 부재, 개별 저작권 고지 보존, 중복 등록 방지와 320px 화면의 두 배 글자 크기를 확인했다.

정적 분석에서도 문제가 없었다. 이번 간소화에서는 네이티브 의존성을 바꾸지 않았으며 Android APK를 다시 빌드하거나 실제 기기에 설치하지 않았다. 실제 기기의 외부 브라우저 실행과 원문 응답은 위 수동 절차로 확인한다.
