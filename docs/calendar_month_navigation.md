# 캘린더 연·월 선택과 스와이프

브랜치: `feature/calendar-month-navigation` · 대상: [추가 요구사항](pre-release-additional-requirements.md)의 U-08/U-09.

## 사용 방법

- 캘린더 상단의 연·월을 누르면 `연·월 선택` 창이 열린다.
- 연도를 입력하고 1~12월 중 원하는 월을 선택한 뒤 `이동`을 누른다. 날짜까지 선택할 필요는 없다.
- `취소`하거나 창을 닫으면 기존 월을 유지한다. 잘못된 연도는 창을 닫지 않고 오류를 표시한다.
- 달력 영역을 왼쪽으로 밀면 다음 달, 오른쪽으로 밀면 이전 달로 이동한다.
- 기존 이전/다음 달 화살표와 `이번 달로 이동` 버튼은 유지한다.

연도 입력은 1~9999 범위의 숫자를 허용한다. 연도 경계를 넘어 월을 이동하며, 1년 1월 이전이나 9999년 12월 이후로는 이동하지 않는다. 작은 화면·큰 글자·키보드가 열린 상태에서도 선택창을 스크롤해 사용할 수 있다.

## 제스처와 화면 상태

가로 이동과 세로 스크롤은 별도의 제스처로 처리한다. 짧은 가로 움직임은 월 이동으로 처리하지 않고, 드래그가 끝났을 때 한 번만 이동한다. 날짜 탭, 여러 날짜에 걸친 기록 막대 아래의 날짜 선택, 달력의 세로 스크롤은 유지한다.

월이 바뀌면 새 월의 달력을 맨 위부터 표시한다. 월 선택창을 연 뒤 계정·세션이 변경되거나 캘린더가 비활성화되면 이전 선택 결과를 적용하지 않는다.

## 기록 조회·캐시

직접 선택·스와이프·화살표·이번 달 이동을 같은 월 변경 처리에 연결했다. 기존 `PaidRecordCacheService.holdMonth/loadMonth` 경로를 그대로 사용한다.

- 같은 월을 다시 선택하면 보유 중인 월을 해제·재등록하거나 서버 조회를 반복하지 않는다.
- 무료 회원은 로컬 기록을 사용하고, 유료 회원의 과거 월은 기존 정책에 따라 선택한 월의 범위만 조회한다.
- 오프라인에서는 내려받은 기록과 기존 안내를 유지한다. 조회 실패 시 기존 재시도 경로를 사용한다.
- 이전 월의 응답이 늦게 도착해도 해당 월의 보유 상태·세션 검사를 거쳐 현재 선택을 덮어쓰지 않는다.
- 비활성 캘린더는 새 조회를 시작하지 않는다.

서버 권한·31일 기본 캐시·사진 보존·기록 모델·DB 스키마는 변경하지 않는다. 새로운 패키지나 Firebase 규칙·인덱스 배포도 추가하지 않는다.

- `test/calendar_month_navigation_test.dart`: 스와이프 방향과 연도 경계, 화살표·이번 달 이동, 짧은 가로 움직임·세로 스크롤, 기록 막대 탭, 계정 변경 후 이전 선택 무시.
- `test/calendar_month_cache_navigation_test.dart`: 유료 월 범위 조회와 중복 방지, 무료 로컬 조회, 오프라인 캐시, 늦은 이전 월 응답 거부, 비활성 조회 방지.
- 기존 연속 기록 막대·과거 기록·기본 화면 테스트로 기존 동작을 확인한다. 기본 화면의 월 이동 테스트는 실제 접근 조건에 맞춰 무료 회원 세션을 명시한다.

2026-11-16 신규 테스트 23개를 포함한 **전체 Flutter 테스트 1,519개와 정적 분석이 통과**했다. 변경 Dart 파일 6개의 포맷 검사와 `git diff --check`도 통과했다. 실제 기기 조작과 최종 빌드·배포는 실행하지 않았다.

## 실제 기기 확인

1. 연·월을 눌러 다른 연도와 월을 선택해 이동한다. 다시 선택창을 열면 현재 표시 중인 연·월이 선택되어 있어야 한다. `취소` 시 달력이 바뀌지 않아야 한다.
2. 왼쪽·오른쪽으로 밀어 한 달씩 이동한다. 12월↔1월의 연도 변경과 화살표·이번 달 버튼도 확인한다.
3. 달력을 세로로 스크롤하거나 날짜·연속 기록 막대 아래를 누른다. 의도하지 않은 월 이동 없이 해당 날짜의 기록 목록이 열려야 한다.
4. 유료 계정으로 기록이 있는 과거 월을 선택한다. 비행기 모드에서는 이미 내려받은 기록과 오프라인 안내를 확인하고, 무료 계정에서도 로컬 기록 조회가 유지되는지 확인한다.
5. 글자 크기를 크게 설정하고 연·월 선택창을 연다. 키보드가 표시되어도 월 선택과 이동·취소 버튼을 사용할 수 있어야 한다.
