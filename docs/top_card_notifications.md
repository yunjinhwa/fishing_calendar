# 공통 상단 카드 알림

브랜치: `feature/top-card-notifications` · 대상: [추가 요구사항](pre-release-additional-requirements.md)의 U-06.

로그인·회원가입, 기록 저장·삭제·공유, 네트워크·오프라인, 플랜·동기화, 지도 대체 화면과 앱 정보의 일시 상태 알림을 공통 상단 카드로 바꿨다. 기존 메시지, 처리 결과 분기, 인증·플랜 접근 조건은 유지한다. 삭제·탈퇴·로그아웃·작성 취소 등의 확인 대화상자와 폼 내부 오류·비밀번호 재설정 안내는 기존 흐름을 유지한다.

## 표시와 닫기

- [TopCardNotification](../lib/presentation/common/top_card_notification.dart)의 `show(context, message)`를 사용한다. 안내·성공·주의·오류를 색상과 아이콘으로 구분한다.
- 카드는 안전 영역과 상단 툴바 아래에 뜨며 본문을 밀지 않는다. 카드 바깥의 화면은 계속 조작할 수 있다.
- 기본 표시 시간은 4초이며 `알림 닫기` 버튼으로 즉시 닫을 수 있다. 새 알림은 이전 알림을 교체하고 표시 시간을 새로 시작한다. 대기열에 쌓지 않는다.
- 작은 화면·큰 글자·키보드 높이에 맞춰 카드 높이를 제한하고 긴 문구는 카드 안에서 스크롤한다. 사용할 수 있는 높이가 부족하면 카드를 숨긴다.
- 화면 읽기 프로그램을 위한 live region을 제공한다. 접근성 탐색이 켜져 있으면 자동으로 닫지 않고 사용자가 닫거나 화면을 이동할 때까지 유지한다.

## 화면·세션 경계

[앱](../lib/app.dart)의 루트 Navigator와 [AppShell](../lib/presentation/shell/app_shell.dart)의 캘린더 Navigator에 알림 관찰자를 연결했다. 화면 push·pop·교체·제거 및 대화상자 진입 시 기존 알림을 정리한다.

- 기록 저장·삭제·충돌 해결처럼 완료 직후 이전 화면으로 돌아가는 경우에만 `persistAfterPop: true`를 지정해 성공 알림을 한 번 유지한다. 이후 화면 이동에서는 닫힌다.
- 탭 이동과 캘린더 탭 초기화 시 기존 알림을 닫는다. 비활성 탭이나 다른 화면에 가려진 탭의 늦은 처리 결과는 표시하지 않는다.
- 세션 세대가 바뀌거나 앱이 백그라운드로 이동하면 알림을 닫는다. 이전 세션·비활성 탭에서 남은 결과가 현재 화면에 새 알림을 띄우지 않도록 표시 범위를 검사한다.
- 카드가 닫히거나 화면이 해제되면 타이머와 경로 감시를 정리한다.

## 검증 범위

[공통 위젯 테스트](../test/top_card_notification_test.dart)는 상단 배치와 본문 조작, 기본 자동 닫힘·직접 닫기, 연속 교체와 타이머, 접근성, 좁은 화면·큰 글자·키보드, 화면 이동과 완료 후 복귀, 비활성 탭, 백그라운드 전환 및 앱 해제를 다룬다.

화면별 회귀 검증 대상은 인증 처리·이동 제한, 기록 저장·삭제·공유, 네트워크 재확인, 플랜·업로드 대기열·충돌 처리, 탭·계정 전환과 기존 확인 대화상자다. [앱 위젯 테스트](../test/widget_test.dart)에서는 다음 프레임 전의 탭 전환 경합, 동일 계정 갱신 시 카드 보존, 계정 변경 시 기존 탭 컨텍스트 해제도 확인한다.

2026-11-16 실행 결과:

| 검증 | 결과 |
|---|---|
| 전체 Flutter 테스트 (`flutter test --no-pub`) | 1,532개 통과 |

새 알림 테스트는 공통 위젯 11개와 실제 앱의 탭·계정 전환 2개다. 외부 링크 재시도 테스트는 상단 오류 카드를 닫고 원래 링크를 다시 누르는 흐름으로 맞췄다. 최종 빌드·배포는 실행하지 않았다.

## 수동 확인 절차

테스트 계정·테스트 기록을 사용한다. 다음 실제 기기 확인과 최종 빌드·배포는 아직 실행하지 않았다.

| 확인 항목 | 절차와 기대 결과 |
|---|---|
| 상단 배치 | 로그인 입력을 비운 채 제출하거나 네트워크 재확인을 실행한다. 카드가 상단에 표시되고 본문 위치와 카드 바깥 조작이 유지되어야 한다. |
| 자동·직접 닫기 | 기본 알림이 약 4초 후 사라지는지 확인한다. 다시 띄운 뒤 `알림 닫기`를 누르면 즉시 사라져야 한다. |
| 연속 알림 | 다른 입력 오류를 연속으로 발생시킨다. 최신 카드 하나만 남고 그 알림 기준으로 표시 시간이 시작되며 이전 알림이 다시 나타나지 않아야 한다. |
| 키보드·큰 글자 | 작은 화면에서 글자 크기를 키우고 키보드를 연 채 긴 오류 문구를 표시한다. 문구를 스크롤하고 닫기 버튼을 사용할 수 있어야 한다. |
| 화면 이동·완료 | 알림 표시 중 화면 진입·뒤로 가기·확인창 열기를 실행하면 기존 카드가 사라져야 한다. 기록 저장·삭제·충돌 해결 완료 후 복귀할 때는 성공 카드가 보이고 다음 화면 이동에서 사라져야 한다. |
| 탭 이동 | 알림 표시 중 다른 탭으로 이동하고 진행 중 작업이 끝날 때까지 기다린다. 이전 탭 알림이 재등장하지 않아야 한다. 캘린더 탭 재선택도 확인한다. |
| 계정·앱 상태 | 알림 표시 중 로그아웃·재로그인·계정 전환 또는 앱 백그라운드 전환을 수행한다. 이전 계정·화면의 카드가 복귀 후 남거나 늦게 나타나지 않아야 한다. |
| 확인창 보존 | 기록 삭제·회원 탈퇴·로그아웃·작성 취소의 확인창을 열고 취소한다. 기존 확인 문구·취소·확정 동작과 인증·플랜 접근 절차가 유지되어야 한다. |
| 접근성 | 화면 읽기 프로그램을 켜고 알림을 발생시킨다. 메시지를 인식할 수 있고 4초가 지나도 카드가 유지되며 닫기 버튼으로 종료할 수 있어야 한다. |
