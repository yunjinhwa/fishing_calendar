# 어류 상세정보 제공 범위 점검

## 전체 800종 수집 결과 — 2026-11-06

주요 어종 제한 없이 기본 목록의 **800종 전체**를 다음 네 경로에서 대조했다. MBRIS 전체 원본과 한국어 위키백과, 영어 위키백과의 사진 전용 경로, iNaturalist를 사용하는 사진 수집 경로 모두 미점검 0종이다. 이미 검증된 사진은 재사용해 불필요한 원격 호출을 줄인다. 영어 문서에서는 학명과 대표 사진만 확인하며 영어 설명을 한국어 설명으로 표시하지 않는다.

| 앱 기본 제공 항목 | 최종 종 수 |
|---|---:|
| 전체 목록·대조 완료 | 800 |
| 한국어 설명 | 588 |
| 검증된 실제 사진 연결 | 431 |
| 원문에 근거한 크기 | 282 |
| 별도 상세 서식지 | 14 |

`assets/data/fish_enrichment.json`은 수집 보고서에서 자동 생성한 약 1.43MB의 공개 데이터다. 설명·사진 중 하나 이상을 확보한 671종을 포함한다. 전체 800종의 제공 여부와 경로별 결과는 [전체 자료 현황](fish_enrichment_inventory.json)에 공개 데이터만 기록한다. 빈 항목은 해당 검증 경로에서 자료·정확한 종 연결·이용조건을 확보하지 못했다는 뜻이며, 모든 제공처에 자료가 없다는 뜻은 아니다. 800종을 대조했다는 사실과 800종의 모든 필드가 채워졌다는 주장을 구분한다.

MBRIS에서 499종의 설명과 국내·해외 분포를 얻었다. 전체 22,704건으로 안내된 원본 중 1건이 누락되는 페이지 오류는 기록하고 관련 18종을 개별 조회해 보완했다. 한국어 경로에서는 설명 214종, 영어 사진 전용 경로에서는 사진 304종을 검증했다. 별도 사진 수집 경로는 검증된 재사용을 포함해 사진 276종·해당 경로에서 미확보 464종·종 연결 미확정 60종으로 끝났고 통신 실패·미점검은 0종이다. 경로별 집계는 서로 중복되므로 합산하지 않는다.

최종 앱 자료는 새 MBRIS 설명을 우선하고 이미 검증된 다른 자료원의 크기는 독립적으로 보존한다. 크기만 남기기 위해 더 자세한 설명을 버리지 않으며, 크기 발췌문과 해당 출처·이용조건은 `sizeProvenance`에 저장한다. 설명·사진·크기·서식지는 각각의 검증된 근거로 채우며, 어종별 조건문이나 추측한 수치를 추가하지 않는다. 사진은 연결 정보이므로 최초 이미지 다운로드에는 인터넷이 필요하다.

후속 공식 사진 수집: 갈치의 기본·대표 iNaturalist 사진은 비영리 이용 조건이어서 제외되었지만, [국립수산과학원 어종별 안내](https://www.nifs.go.kr/contents/actionContentsCons0088.do)에 정확한 학명과 개별 공공누리 제1유형 표시가 있는 실제 사진이 확인됐다. 이 페이지를 새 수집 경로로 추가해 국명·학명·개별 이용조건을 전체 목록과 자동 대조했다. 33종이 정확히 일치하며 기존 빈 사진 11종을 추가해 최종 사진 연결은 431종이다. 갈치·개서대·눈퉁멸·덕대·민어·보구치·용서대·줄삼치·짱뚱어·참서대·참조기가 이번에 보강됐다. 갈치 사진은 실제 파일을 내려받아 육안으로 확인했다. 배포 데이터에는 공식 워터마크가 있는 원본 URL을 유지한다.

`python tool/collect_nifs_fish_photos.py`로 위 페이지를 수집하며, 생성된 `.dart_tool/fish_nifs_public_photos.json`을 병합 보고서의 마지막에 추가한다. 수집기는 어종별 조건문을 사용하지 않는다. 해당 어종 구역 안의 제1유형 표시·정확한 국명/학명·대표 사진을 모두 확인하고, 지도·다른 어종·다른 이용유형·외부 도메인은 제외한다. 전체 현황에는 `nifsPublicPhotos` 경로를 포함한다. 오프라인 파서 검증은 `python -m unittest tool/test_collect_nifs_fish_photos.py`로 실행한다.

수집은 아래 도구로 자동 수행하며, 중단된 실행은 공개 점검 파일에서 이어서 처리한다. MBRIS만 기존 `fish.local.json` 인증키를 사용한다. 완료된 보고서는 재사용하며, 이 명령들이 완료 자료를 매번 새로 조회하는 것은 아니다.

```powershell
& "C:\flutter\bin\dart.bat" run tool/collect_all_mbris_fish.dart
& "C:\flutter\bin\dart.bat" run tool/collect_all_wiki_fish.dart
& "C:\flutter\bin\dart.bat" run tool/collect_all_wiki_fish.dart --english-photos
& "C:\flutter\bin\dart.bat" run tool/collect_all_fish_photos.dart
```

기존 검수 자료와 새 보고서를 병합할 때는 `build_fish_enrichment.dart`에 아래 순서대로 `--report=경로`를 전달한다: `fish_priority_extra_photos`, `fish_all_mbris_content`, `fish_detail_audit_recovery`, `fish_priority_public_content`, `fish_priority_korean_content`, `fish_priority_reviewed_descriptions`, `fish_all_wiki_content`, `fish_all_english_photos`, `fish_all_public_photos`. 각 파일은 `.dart_tool/파일명.json`에 있다. 생성 후 `dart run tool/write_fish_inventory.dart`로 전체 현황을 갱신한다. 빌드·현황 도구는 API나 인증키를 읽지 않는다.

아래의 41종·31종 집계는 전체 수집 전의 초기 보강 이력이다.

## 초기 기본 포함 자료 이력 — 2026-11-06

이전 점검 보고서에만 있던 공개 자료를 `assets/data/fish_enrichment.json`으로 묶어 앱에서 실제로 읽도록 연결했다. 다음 수치는 원격 조회 성공률이 아니라 **기본 800종을 읽은 직후 앱 모델에 제공되는 자료**다. 기존 코드의 검수 사진·번역 보완까지 합산하며 중복 어종은 한 번만 센다.

| 항목 | 이전 앱 기본 포함 | 보강 후 기본 포함 |
|---|---:|---:|
| 기본 어종 목록 | 800 | 800 |
| 한국어 설명 | 4 | 41 |
| 검증된 실제 사진 연결 | 3 | 31 |
| 설명에 근거한 크기 | 1 | 17 |
| 수역 분류보다 구체적인 서식지 | 0 | 7 |

보강 JSON에는 41종의 설명·29종의 사진 연결·17종의 크기·7종의 상세 서식지가 들어 있다. 기존 검수 사진에서 가라지·가시가자미 2종을 더해 앱의 사진 연결은 31종이다. 사진 바이너리를 앱에 포함한 것은 아니므로 처음 사진을 내려받을 때 인터넷이 필요하다. 설명·크기·서식지·사진 연결 메타데이터는 첫 설치의 오프라인 상태에서도 사용할 수 있다.

주요 25종을 별도로 선정해 확인했으며 설명 23종·사진 연결 17종·크기 9종을 포함한다. 감성돔·넙치·참돔·돌돔·벵에돔·고등어·조피볼락·쏘가리·붕어·잉어 등이 대상이다. 점농어·배스는 이번에 국명과 학명이 일치하는 설명을 확인하지 못해 보강하지 않았다. 800종 전체가 채워진 것은 아니며, 보강 자료 밖의 어종은 기존 원격 경로에서 계속 조회한다. 아직 확보하지 못한 항목을 제공처에도 자료가 없다고 단정하지 않는다.

한국어 해양 어종 설명은 MBRIS의 일치하는 자료를 우선한다. 민물 6종은 원문·학명·국명을 확인한 한국어 위키백과·위키문헌의 짧은 한국어 요약과 서식지를 포함한다. 붕어·잉어는 현재 위키백과의 국명과 기본 목록 학명이 서로 달라 해당 문서를 무리하게 합치지 않고, 학명이 일치하는 위키문헌의 고정 개정판을 사용한다. 무지개송어의 기존 NIFS 수역 분류는 변경하지 않았으며 분류와 서식지 설명의 차이는 별도 분류 검토 대상으로 남긴다.

돌돔의 먹이 변화가 시작되는 `전장 10cm 이상`을 성어의 크기로 표시하지 않도록 제외했다. 일반 길이·최대 길이·성별·연령 조건은 원문대로 유지하며 수치가 없는 종에는 값을 생성하지 않는다. 원본 설명과 서식지, 사진의 출처·작가·라이선스는 자료에 보존하지만 목록·상세 UI에는 표시하지 않는다.

기존에 저장한 빈 상세와 최신 목록 캐시가 새 보강 자료를 가리지 않도록 표시 시 병합한다. 이미 유효한 원격 정보는 보존하고, 이 병합만으로 캐시 시각을 갱신하지 않는다. 일시적인 부분 조회 실패에는 재시도 문구를 표시한다. 일부 정보가 없다는 이유로 유효한 사진이나 설명을 삭제하지 않는다.

보강 자료를 다시 만들 때는 공개 점검 보고서를 입력한다. 도구는 네트워크나 로컬 인증키를 읽지 않으며, 검증된 필드만 선택한다. 먼저 제공한 유효 사진을 유지하고 설명은 MBRIS를 우선한다. 실패·미점검 결과는 제외하지만 사진만 성공한 부분 결과는 보존한다. 상세 서식지는 명시적인 HABI 또는 같은 출처·이용조건을 가진 검수 설명에 연결되어야 한다.

```powershell
& "C:\flutter\bin\dart.bat" run tool/build_fish_enrichment.dart --report=.dart_tool/fish_priority_extra_photos.json --report=.dart_tool/fish_detail_audit_recovery.json --report=.dart_tool/fish_priority_public_content.json --report=.dart_tool/fish_priority_korean_content.json --report=.dart_tool/fish_priority_reviewed_descriptions.json
```

점검 보고서는 로컬 자료이며 Git에서 제외된다. 배포에는 검증된 공개 정보만 담은 보강 JSON과 개별 이용조건을 포함한다. 생성 시각을 새 조회 시각으로 사용하지 않고 선택한 필드 중 가장 오래된 확인 시각을 해당 프로필에 유지한다. 이전 전체 20종 비교와 호출 제한 결과는 아래에 이력으로 보존한다.

## 이전 원격 조회 비교

2026-11-05, 현재 앱의 800종 목록에서 동일한 첫 20종을 골라 실서비스를 순차 조회했다. Wiki 단독, MBRIS+Wiki, 추가 보완 경로의 결과를 비교했다. 임의로 전체 800종에 이 비율을 적용하지 않는다. 최신 결과에는 공식 API 조회와 원문을 확인해 앱에 포함한 한국어 번역·요약이 함께 반영되어 있다.

| 확인 항목 | Wiki 단독 | MBRIS+Wiki | 누락 보완 적용 후 |
|---|---:|---:|---:|
| 조회 완료 | 20 | 20 | 20 |
| 한국어 설명 | 6 | 15 | 20 |
| 연결 이미지(당시 삽화 포함) | 15 | 15 | 16 |
| 명시적인 최대 길이 | 0 | 0 | 0 |
| 설명·사진 중 하나 이상 | 15 | 18 | 20 |
| 모두 미제공 | 5 | 2 | 0 |
| 통신·서비스 실패 | 0 | 0 | 0 |
| 아직 점검하지 않은 종 | 780 | 780 | 780 |

위 표는 실제 사진만 사용하라는 요청 이전의 비교다. 당시 사진으로 집계한 연결 이미지에는 Naturalis의 수채화가 섞여 있었으므로 실제 사진 확보율로 해석하면 안 된다. 이름·학명·이용조건이 확인된 자료의 연결 결과이며, 최대 길이는 원문에 명시된 값만 허용했다. 최신 실제 사진 전용 점검은 아래에서 별도로 구분한다.

별도 실제 조회로 넙치·감성돔·조피볼락의 MBRIS 한국어 설명을 확인했다. 원문 학명에 저자명이 붙는 실제 응답은 명시적인 `SpcScitfNmShort`로 비교한다. 반환된 정명도 해당 전체 학명이나 짧은 학명에 일치해야 한다. 붕어는 이번 조회에서 검증된 MBRIS 결과를 얻지 못했다.

줄망둑은 한국어 문서가 없어도 정확한 종과 이용조건이 확인된 Commons 사진을 실제로 제공받았다. 사진 요청은 HTTP 206/JPEG로 확인했다. 감성돔·넙치의 설명·사진 조회도 함께 확인했다.

추가 보완으로 가시납지리의 iNaturalist 사진(A. C. Tatarinov, CC BY-SA 4.0)을 실제로 받았고 HTTP 206/JPEG 다운로드를 확인했다. GBIF의 현재 COL XR에서 `Acheilognathus chankaensis`가 `Acanthorhodeus chankaensis`로 연결되는 두 단계 응답을 확인했으며, 새 학명과 국명이 일치하는 한국어 위키백과 설명도 복구했다. 목록의 기존 학명과 식별자는 유지한다.

가는곰치·가시전갱이·가시줄고기·각시가자미는 기존 표본에서 설명이 없던 종이다. 영어 문서 개정판의 학명·분류 항목 연결을 확인한 뒤 짧은 한국어 번역·요약을 앱에 포함했다. 실행 중 자동 번역이나 추측한 크기 추가는 하지 않는다. 상세 출처·개정판·번역 사실은 모델과 [라이선스 안내](../third_party/fish_encyclopedia_NOTICE.txt)에 남긴다. 보완 이후에도 표본 20종 중 4종의 사진은 검증된 자료를 찾지 못했다.

## 재현과 전체 점검

실제 사진만 사용하라는 요청 이후, 가라지·가숭어·가시가자미의 Commons 파일을 직접 내려받아 사진 내용과 학명·국명·작가·이용조건을 확인했다. 검수된 3종은 [검수 사진 목록](../lib/data/fish/reviewed_fish_photos.dart)에 포함하며 상세 설명 조회 없이 사용할 수 있다. 가시가자미는 실제 보존 표본 사진과 방사선 사진으로 구성된 원본 도판이다. 이름·학명이 다르거나 이미 유효한 실제 사진이 있으면 이 보완 자료로 덮어쓰지 않는다.

명시적인 수채화·삽화·분포도·AI 생성물은 Commons 파일명과 설명 메타데이터에서 제외하며, 이전 캐시의 명시적 삽화도 목록·상세에서 표시하지 않는다. 메타데이터만으로 모든 이미지의 형태를 완전히 판독할 수 있다고 가정하지 않는다. 누락된 종에 다른 어종 사진이나 생성 그림을 넣지 않는다.

실제 사진 전용 점검 결과는 `.dart_tool/fish_actual_photo_audit.json`이다. 이 모드는 MBRIS와 로컬 인증키를 사용하지 않는다. 최신 재점검은 16종에서 사진 성공 8종·제공처 호출 제한 8종을 기록하고 연속된 일시 실패 3회에 중단했다. 나머지 784종은 이 실행에서 미점검이며, 호출 제한과 미점검은 사진 없음으로 간주하지 않는다. 따라서 이 중단된 실행의 숫자를 전체 사진 확보율로 해석하면 안 된다. 800종 전체에 실제 사진이 확보되었다는 뜻은 아니며, 사용 가능한 실제 사진을 찾지 못한 항목은 별도 확보 대상으로 남긴다.

```powershell
# 사진만 점검: 설명·인증키 없이 확인, 같은 자료원 구성의 완료 결과는 재사용
& "C:\flutter\bin\dart.bat" run tool/audit_fish_details.dart --photos-only --limit=20 --output=.dart_tool/fish_actual_photo_audit.json

# 전체 800종까지 사진만 순차 점검할 때
& "C:\flutter\bin\dart.bat" run tool/audit_fish_details.dart --photos-only --limit=800 --output=.dart_tool/fish_actual_photo_audit.json
```

이전 비교 결과는 `.dart_tool/fish_detail_audit.json`과 `.dart_tool/fish_detail_audit_mbris.json`, 누락 보완 적용 후 결과는 `.dart_tool/fish_detail_audit_recovery.json`에 있다. 파일은 Git에서 제외되는 공개 자료 점검 보고서이며, 결과별 확인 시각·출처·이용조건을 포함한다. 인증키는 저장하지 않는다. 제공처 구성이 달라지면 이전 완료 결과를 재사용하지 않는다.

```powershell
# 키 없는 경로: Wikimedia 우선 + 누락 보완
& "C:\flutter\bin\dart.bat" run tool/audit_fish_details.dart --limit=20

# 승인된 MBRIS 키를 명시적으로 사용
& "C:\flutter\bin\dart.bat" run tool/audit_fish_details.dart --limit=20 --config=fish.local.json --output=.dart_tool/fish_detail_audit_recovery.json

# 전체 800종을 같은 기준으로 순차 점검
& "C:\flutter\bin\dart.bat" run tool/audit_fish_details.dart --limit=800 --config=fish.local.json --output=.dart_tool/fish_detail_audit_recovery.json
```

각 어종 조회 후 1초 간격을 두고, 항목별로 보고서를 저장한다. 원본 목록의 해시·자료원 구성·어종 식별자가 같은 완료 결과는 이어서 사용할 수 있다. 설정이 달라지면 이전 결과를 새 제공처의 결과로 간주하지 않는다. 실패했거나 일시 장애가 표시된 항목은 다음 실행에서 재점검할 수 있다. 연속된 일시 장애 3회에는 실행을 중단해 서버 장애를 대량 미제공 결과로 기록하지 않는다. 확인하지 못한 항목과 실패한 항목의 제공 여부는 알 수 없음으로 남긴다.

이 도구는 원격 조회와 보고서 생성만 하며 앱의 목록 파일·계정 데이터·Firestore를 변경하지 않는다. 전체 소요 시간은 원격 응답과 캐시 여부에 따라 달라진다.
