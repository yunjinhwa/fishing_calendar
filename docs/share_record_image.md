# 기록어 공유 이미지 (UC-34)

내정보 → 내 기록어 → 어종 상세 → 크기 기록 또는 무게 기록 선택 → 공유 이미지 미리보기에서 사용한다. 무료·유료 회원 모두 이용할 수 있다. 서버 업로드 없이 기기에서 PNG를 생성한다.

## 표시 기준

- 선택한 조과 **한 건**의 크기·무게를 표시한다. 최고 크기 60cm·400g과 최고 무게 40cm·1,200g이 별도 조과라면 크기 기록 공유는 60cm·400g, 무게 기록 공유는 40cm·1,200g이다.
- 어종명·기록 기준·FishingBuild 표시는 항상 포함된다. 닉네임·출조 사진·크기·무게는 기본 포함하며 각각 끌 수 있다.
- 날짜·장소는 기본 제외이며 사용자가 선택해야 포함된다. 이메일·계정 ID·좌표·메모·파일 경로는 이미지와 파일명에 넣지 않는다. 닉네임이 없으면 `낚시인`으로 표시한다.
- 사진은 해당 출조의 사진이다. 여러 장이면 한 장을 선택할 수 있다. 사진이 없거나 기기에 파일이 없으면 대체 표시를 사용한다. 없는 측정값은 `미측정`으로 표시한다.
- 미리보기는 고정된 글자 크기로 구성한 세로 카드이며, 저장 PNG는 가로 1,080px이다. 사진은 비율을 유지하며, 카드 크기에 맞춰 디코딩한다.
- 카드 배경에는 옅은 수채화 바다·낚싯대 그림을 사용한다. 그림은 앱에 포함된 로컬 이미지이며 저장·공유 전 로딩을 기다린다. 사용자 출조 사진은 별도 영역에 원본 비율로 표시한다. [배경 파일·생성 프롬프트](share_record_background.md)

## 저장·공유

Android/iOS에서 **이미지 저장**은 사진 갤러리에 PNG를 저장하며 필요한 경우 저장 권한을 요청한다. Windows/macOS/Linux에서는 저장 위치 선택창을 사용한다. Android/iOS/macOS/Windows의 **공유하기**는 OS 공유 화면을 연다. 공유 앱 선택 안내는 실제 메시지 전송 완료를 의미하지 않는다. 취소·권한 거부·저장 공간 부족·미지원 환경에서는 상황에 맞게 안내하고 재시도할 수 있다. 웹 저장·공유와 Linux 공유는 현재 지원하지 않는다.

미리보기 진입·옵션 변경·닫기만으로 갤러리 파일이나 공유 임시 파일을 만들지 않는다. 저장·공유 버튼을 누를 때 카드만 캡처한다. 같은 미리보기의 PNG를 재사용하고 옵션·사진·원본이 바뀌면 다시 생성한다. 중복 누르기는 작업 중 차단한다.

공유용 파일은 앱 임시 폴더의 임의 이름 하위 폴더에 둔다. OS에 넘긴 파일은 수신 앱이 읽을 수 있도록 즉시 지우지 않으며, 다음 공유 요청에서 24시간 지난 파일을 정리한다. 보관 한도는 128개·128MiB이다. Firebase Storage·Firestore 공유 이력·새 DB 테이블은 추가하지 않는다. 기록어 조회에는 기존 전체 이력 보관 정책을 사용하며 옵션 변경 때문에 서버를 다시 읽지 않는다.

미리보기를 연 뒤 계정·닉네임·선택 조과·사진·날짜·장소가 바뀌면 이전 카드를 숨기고 내보내기를 중단한다. 기록 변경은 **최신 기록으로 새로고침** 후 다시 확인할 수 있다. 로그아웃·계정 전환·탈퇴 대기 상태에서는 공유를 중단한다. 이미 OS나 다른 앱에 넘긴 이미지는 회수할 수 없다.

## 개발 환경

새 네이티브 플러그인(`share_plus`, `gal`, `file_selector`)이 포함되어 실행 중인 앱은 종료 후 다시 빌드해야 한다. 기존 Firebase·지도 실행 설정을 그대로 사용하며 별도 API 키는 필요 없다. Android는 AGP 8.12.1, macOS 최소 지원 버전은 플러그인 요구에 따라 11.0이다. iOS 갤러리 추가 권한 설명과 Android 구형 OS 저장 권한을 추가했다.

## 자동 검증

2026-11-08 기준 전체 Flutter 테스트 **1,222개 통과**(공유 관련 신규 55개 포함), 전체 코드 분석 이상 없음, Android debug APK 빌드 성공. 실제 기기 설치·조작은 수행하지 않았다.

`test/share_record_data_test.dart`, `test/share_record_card_test.dart`, `test/share_record_page_test.dart`, `test/share_image_exporter_test.dart`에서 단일 조과 연결·기본 개인정보 제외·사진 누락·선택 항목·긴 문구·작은 화면·실제 PNG 디코딩·재시도·취소·원본 변경·계정 변경·내보내기 도중 뒤로가기·플랫폼 권한/결과·공유 임시 파일 처리를 검증한다. 플랫폼 테스트는 가짜 어댑터를 사용하므로 실제 OS 갤러리·공유 화면 동작은 아래 절차로 확인한다.

## 실제 기기 확인

1. 서로 다른 기록에 같은 어종으로 **60cm·400g**, **40cm·1,200g**과 다른 사진을 저장한다. 상세에서 크기/무게 기준을 바꿔 각각의 미리보기가 해당 조과의 수치·사진을 표시하는지 확인한다.
2. 날짜·장소가 기본 제외되는지 확인한다. 포함 항목을 켜고 끄거나 출조 사진을 바꿔 카드가 즉시 바뀌는지 확인한다.
3. **이미지 저장**을 누르고 갤러리에서 글자·사진·크기·무게·선택 항목이 미리보기와 일치하는지 확인한다. 앱의 버튼·설정 항목은 이미지에 없어야 한다.
4. **공유하기**에서 공유 앱을 선택하고 상대 앱에서 이미지를 확인한다. 공유창을 취소한 뒤에도 저장·다시 공유가 가능해야 한다. 미리보기에서 뒤로가면 추가 파일 저장이나 공유창이 없어야 한다.
5. 사진 없는 기록과 사진이 없는 다른 기기에서도 대체 표시로 저장되는지 확인한다. 저장 권한을 거부한 경우 안내가 나오며, 권한을 허용하고 재시도할 수 있어야 한다.
6. 무료 회원·온라인 유료 회원·오프라인의 기기 내 기록에서 사용한다. 미리보기 중 다른 기기로 기록을 수정·삭제하면 이전 카드가 숨겨지고 새로고침을 요구해야 한다. 로그아웃·탈퇴 상태에서는 공유 버튼이 없어야 한다.

실제 기기 테스트는 사용자가 수행한다. Windows 환경에서 iOS/macOS 빌드와 해당 OS 권한창은 검증하지 않는다.
