# 로컬 사진 파일 정리

사진은 계속 기기에만 보관한다. 이 작업은 사용하지 않는 앱 전용 복사본을 정리하며, 갤러리 원본이나 외부 경로의 파일을 삭제하지 않는다.

## 사진을 보존하는 기준

삭제 전에 SQLite의 모든 계정을 대상으로 다음 참조를 확인한다.

- 저장된 기록의 사진
- 미완료 Outbox의 사진: 대기·전송 중·실패·충돌 상태
- 미해결 또는 해결 전송 중인 충돌의 로컬·서버 스냅샷 사진
- 무료 상태에서 생성·수정한 기록의 변경 이력 사진
- 아직 가져오지 않은 격리된 이전 버전 기록의 사진
- 현재 열린 작성·수정 화면에서 사용하는 사진

같은 경로를 여러 기록·화면이 사용하면 마지막 참조가 없어질 때까지 보존한다. 완료된 Outbox와 해결 완료된 충돌의 과거 스냅샷, 무료 상태의 삭제 이력은 사진 복구에 사용하지 않으므로 파일을 계속 보존하는 근거로 삼지 않는다. 무료 삭제 이력 자체는 유지되어 유료 재전환 시 서버 삭제를 전파한다.

## 작성과 정리 시점

- 새로 선택한 사진은 기존의 앱 내부 경로에 복사하고, 작성 화면이 열려 있는 동안 임시 참조로 보호한다. 저장·전송 payload의 경로를 나중에 바꾸지 않는다.
- 저장하지 않은 사진을 제거하거나 작성을 취소하면 사용하지 않는 복사본을 정리한다.
- 기존 사진을 제거한 뒤 저장에 실패하거나 변경을 버리면 저장된 기록의 참조가 남으므로 파일도 유지한다. 제거 저장이 성공하면 참조가 사라진 파일을 정리한다.
- 기록 삭제와 다른 기기의 삭제 반영 후에도 같은 기준으로 정리한다. 미완료 전송이나 열린 편집 화면이 사용 중이면 참조가 끝날 때까지 보존한다.
- 앱 시작·로그인, 기록·충돌 데이터 변경, 전송 완료 또는 실패 시 정리를 요청한다. 강제 종료로 남은 미사용 사진과 임시 쓰기 파일도 다음 정리에서 회수한다.
- 계정이 바뀐 작성 화면에서는 새 사진을 다른 계정에 첨부하거나 저장하지 않는다. 원래 작성한 입력은 유지하고 계정 변경을 안내한다.

파일 저장과 정리는 하나의 작업 큐에서 직렬화한다. 참조 조회와 정리는 DB 트랜잭션으로 묶고, 파일 삭제 직전에도 열린 화면의 참조를 재확인한다. 사진 선택 완료 전에 화면이 닫혀도 쓰기 완료 후 참조를 해제하여 복사본이 방치되지 않도록 한다.

## 오류와 경로 안전성

- JSON·사진 참조 구조 또는 DB 조회에 문제가 있으면 그 정리 작업은 삭제를 시작하지 않는다.
- 파일 정리 실패를 기록 저장 실패로 표시하지 않는다. 이후 정리 요청에서 다시 시도한다.
- 현재 대상 계정의 앱 전용 사진 폴더 안에서만 정상 파일을 정리한다. 심볼릭 링크·Windows junction과 우회 경로는 따라가지 않는다. 경로를 확실히 검증할 수 없으면 삭제하지 않는다.
- 다른 계정에서 참조하는 경로도 보호한다. 다른 계정의 폴더를 현재 계정의 정리 대상으로 삼지 않는다.

## 실제 기기 확인

1. 새 기록에 사진을 첨부하고 **나가기**로 작성을 버린다. 기록은 생성되지 않고 갤러리 원본은 남아야 한다.
2. 사진이 있는 기존 기록에서 사진을 제거한 뒤 **계속 작성** 또는 변경 폐기를 선택한다. 저장하지 않고 돌아왔다면 기존 기록의 사진이 정상적으로 보여야 한다.
3. 기존 사진을 제거하고 저장한다. 사진 없는 상태로 유지되고, 앱을 다시 실행해도 사진이 다시 나타나지 않아야 한다.
4. 새 사진을 추가해 저장하고 다시 열거나 앱을 재실행한다. 저장된 사진이 정상적으로 표시되어야 한다.
5. 무료 상태에서 사진이 있는 기록을 삭제한다. 기록이 사라지고 다른 기록의 사진과 갤러리 원본은 유지되어야 한다.
6. 유료 상태에서 오프라인으로 사진이 있는 기록을 생성·수정·삭제한 뒤 연결을 복구한다. 대기열과 충돌 해결이 정상 동작하고, 유지하기로 한 기록의 사진이 사라지면 안 된다.
7. 같은 유료 계정의 다른 기기에서 기록을 삭제한다. 원래 기기에서 삭제가 반영되고, 열린 편집 화면의 사진은 화면을 닫을 때까지 유지되어야 한다. 다른 기기의 사진은 원래 정책대로 동기화하지 않는다.

실제 앱 복사본의 삭제·보존, 강제 종료 잔여 파일, DB·파일 오류 및 링크 경계는 자동 테스트에서 검증한다.
