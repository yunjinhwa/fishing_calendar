# 캘린더의 연속 기록 표시

여러 날짜에 걸친 출조 기록을 날짜별로 반복 표시하는 대신, 같은 주에서는 하나의 파란 막대로 이어 표시한다. 예를 들어 같은 주의 21일 오후 6시부터 22일 오전 3시까지인 기록은 21일과 22일을 연결하는 막대 하나로 표시한다.

## 표시 기준

- 월요일부터 일요일까지를 한 주로 배치한다. 주가 바뀌면 다음 줄에서 막대를 이어 표시하고, 월 경계에서는 현재 월의 날짜까지만 표시한다.
- 실제 시작·종료 쪽은 둥근 모서리, 다른 주·월로 이어지는 쪽은 평평한 모서리로 표시한다. 제목은 각 주의 막대에 한 번 표시한다.
- 기존 날짜 겹침 기준을 유지한다. 종료 시간이 정확히 다음 날 00:00이면 다음 날에는 표시하지 않는다.
- 겹친 기록은 서로 다른 줄에 배치하며, 각 주에서 기록별 줄을 고정한다. 최대 2줄을 표시하고 나머지는 해당 날짜에 `+N`으로 안내한다. 막대의 연속성을 유지하기 때문에 주 앞부분에서 숨겨진 기록은 뒷부분에 빈 공간이 생겨도 그 주에서는 `+N`으로 남을 수 있다.
- 막대 위나 `+N`을 눌러도 누른 날짜의 기록 목록으로 이동한다. 목록에서는 숨겨진 기록까지 모두 확인할 수 있다.
- 글자 크기에 따라 줄 높이를 조정하고, 화면에 다 들어오지 않는 주는 세로로 스크롤한다. 접근성 날짜 설명에는 숨겨진 기록을 포함한 제목도 제공한다.

월에 해당하는 기록만 배치하고, 긴 기간의 기록도 현재 월의 최대 31일 안에서 계산한다. 저장 데이터·날짜 판정·동기화 정책은 변경하지 않으며, 저장소 변경 시 막대도 기존 listener를 통해 갱신한다.

## 실제 기기 확인

1. 같은 주의 21일 18:00~22일 03:00 기록을 저장한다. 두 날짜 사이가 끊기지 않는 막대 하나인지 확인한다. 막대의 21일 쪽과 22일 쪽을 각각 누르면 해당 날짜 목록이 열려야 한다.
2. 토요일~월요일 기록을 저장한다. 토·일 부분과 다음 줄 월요일 부분으로 나뉘어 이어져야 한다.
3. 월말~다음 달 초 기록을 저장하고 월을 이동한다. 현재 월 밖의 빈 칸에는 막대가 나타나지 않고, 다음 달에서는 나머지 기간이 표시되어야 한다.
4. 같은 날짜에 걸친 기록을 3개 저장한다. 막대는 다른 줄에 최대 2개 표시되고, `+1`을 누르면 목록에서 3개 모두 확인할 수 있어야 한다.
5. 21일 18:00~22일 00:00 기록을 저장한다. 막대는 21일에만 있어야 한다.
6. 기록의 종료 날짜를 바꾸거나 삭제한 뒤 돌아온다. 막대 길이·더보기 개수가 갱신되고 삭제한 막대는 사라져야 한다.
7. 기기의 글자 크기를 키우고 확인한다. 막대·날짜·더보기 표시가 겹치거나 화면 밖으로 넘치지 않고, 스크롤과 날짜 선택이 가능해야 한다.
