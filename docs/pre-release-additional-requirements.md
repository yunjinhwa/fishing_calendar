# 수정사항.txt 추가 요구사항 정리

기준 자료: 사용자가 제공한 `수정사항.txt` 및 감사 기준 HEAD `7929bf8`의 관련 화면.

사용자가 추가한 화면 개선·기능 요구사항을 기록한다. 기존 감사의 결함 목록과 함께 우선순위를 정하되, 이 문서 작성으로 구현을 시작하거나 새 브랜치를 만들지는 않았다.

## 권장 작업 묶음

1. 기존 감사 High 2건(A-01 인증 경합, A-02 첫 동기화 충돌 재시도)을 먼저 수정한다. 이후 서버 스키마·시작 복구·테스트 실패 등 감사 항목을 처리한다.
2. 지도·기록 화면 정리: U-01~U-05. 예시 브랜치 `refactor/map-record-ui`. 화면 정보 정리와 내부 좌표 보존을 같이 검증한다.
3. 캘린더 이동: U-08/U-09. 예시 브랜치 `feature/calendar-month-navigation`.
4. 공통 상태 알림: U-06. 예시 브랜치 `feature/top-card-notifications`. 여러 화면을 건드리므로 독립된 변경으로 검토한다.
5. 오늘의 요약: U-07. 예시 브랜치 `feature/calendar-today-summary`. 표시 정보·기준 위치를 확정한 후 진행한다.
6. 프로필 수정: U-10. 예시 브랜치 `feature/profile-settings`. 인증 경합 수정 후 진행하고 닉네임 변경의 서버 데이터 계약을 함께 다룬다.

브랜치 이름은 제안이며 실제 생성·전환은 하지 않았다. 기존 감사와 추가 요구사항은 아직 수정 완료 상태가 아니다.
